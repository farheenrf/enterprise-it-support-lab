# Enterprise IT Support Lab

A hands-on portfolio project demonstrating enterprise IT support, Microsoft 365, Microsoft Entra ID, troubleshooting, identity administration, ticket documentation, automation, and managed-services practices.

## Project Status

In progress — labs and support scenarios will be added as they are completed.

## Lab Environment

This project uses fictional organizations, users, tickets, devices, and business information. No employer or client data is included.

### Fictional Clients

| Client | Industry | Users | Support Model |
|---|---|---:|---|
| Northwind Health | Healthcare | 50 | Microsoft 365 and identity support |
| Contoso Financial | Financial Services | 100 | Managed IT and network support |
| Alpine Consulting | Consulting | 25 | Cloud and end-user support |

## Skills Demonstrated

- Microsoft 365 administration
- Microsoft Entra ID
- User onboarding and offboarding
- Users, groups and role-based access
- MFA and self-service password reset
- Outlook, Teams and OneDrive support
- Windows and endpoint troubleshooting
- VPN, DNS and network-connectivity troubleshooting
- Incident and service-request management
- SLA, priority and escalation management
- PowerShell and Microsoft Graph automation
- Technical documentation and knowledge management

## Planned Labs

1. Create and manage Entra ID users
2. Create security and Microsoft 365 groups
3. Configure authentication methods and MFA
4. Build an employee onboarding workflow
5. Build an employee offboarding workflow
6. Automate bulk-user creation with PowerShell
7. Troubleshoot Microsoft 365 sign-in problems
8. Investigate Outlook, Teams and OneDrive issues
9. Resolve VPN and DNS connectivity incidents
10. Create a managed-services ticket and SLA dashboard

## Repository Structure

- `entra-id-labs/` — Microsoft Entra administration exercises
- `microsoft-365-support/` — Outlook, Teams and OneDrive cases
- `tickets/` — Simulated incidents and service requests
- `powershell/` — Administrative automation scripts
- `knowledge-base/` — End-user and technician documentation
- `project-management/` — Schedule, RAID log and status reports

## Documentation Standard

Every completed lab will include:

1. Objective
2. Environment and prerequisites
3. Implementation steps
4. Screenshots or sanitized evidence
5. Validation
6. Troubleshooting observations
7. Lessons learned
